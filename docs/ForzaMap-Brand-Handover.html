Everything needed to put the ForzaMap identity into production: the locked lockup, the icon range, colour and type specs, spacing rules, and the complete favicon and app-icon asset set. The mark pairs a weight-contrast wordmark with three elevation rules — the terrain read that carries the “Map” without a literal map.

1 · The lockup

Primary. Ink wordmark, Forza rules, optional tagline. Default for reports, decks and the web app header.
Reversed. Paper wordmark with the Lift accent on ink #22201C or darker. Never on mid-tone photography.
One colour. Rules drop to 100 / 55 / 28 % ink. Use for stamped, engraved, single-plate or faxed output, and any context below 88 px where colour would muddy.

2 · Clear space & minimum size

Clear space on all four sides equals the cap height of F. Nothing — rules, images, page trim — enters it.
Minimum width 88 px on screen, 24 mm in print. Below that, drop the tagline; below 64 px use the icon instead.
Never stretch, re-weight, recolour the rules independently, add a stroke or shadow, or set the wordmark in another typeface.

3 · Icon range

The icon simplifies as it shrinks: two rules at 48 px and above, one at 32 px, none at 16 px. Corner radius is 21.7 % of the tile; the maskable variant is square with the mark at 60 % scale.
Tile #2A251F · mark #F4F1EA · rules #C96442 at 100 % and 50 %.

5 · Type

Archivo 800 — Forza
Archivo 400 — Map
The wordmark is Archivo 800 / 400 at −0.035 em tracking, drawn as one unit — never re-typed. Tagline and UI labels: Archivo 500 at +0.07 em. Body copy in reports: Archivo 400. Technical values and codes: JetBrains Mono 400. Both families are open source (SIL OFL) and free for commercial and embedded use.

8 · Before release

  • All lettering ships as outlined vector paths — no font dependency in any SVG or PNG, identical rendering everywhere. The paths are traced from Archivo at high resolution (≈0.2 unit tolerance); a type designer redrawing them as true Bézier curves is the one upgrade worth buying.
  • Commission a proper drawn cut of the wordmark if budget allows — the F/M junctions and the z shoulder want optical correction at large sizes.
  • Add Pantone equivalents for Ink and Forza once a print partner is chosen; the CMYK values above are uncoated-stock estimates.
  • Register forzamap handles and clear the name in the target territory before public launch.
