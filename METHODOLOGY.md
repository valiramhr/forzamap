# Strengths Profile — Methodology

*An original forced-choice strengths instrument for practice, coaching and
assessment-centre use. Inspired by the strengths-assessment format but not
affiliated with, and not reproducing any content from, Gallup's CliftonStrengths®.*

---

## 1. Purpose and positioning

This is a **development and practice instrument**, not a validated selection test.
It produces an *intra-individual* profile — a rank order of a person's own strengths —
to support conversation, coaching and self-reflection. It is deliberately **not
normed**, so it does not place a person against a population and should not be used
to screen or rank candidates against one another (see §7).

## 2. Construct model — themes and domains

The instrument measures **12 themes**, grouped into **4 domains**. The four-domain
taxonomy is the same widely used structure popularised by CliftonStrengths; the
theme names and all statement content are original to this instrument.

| Domain | Themes |
|---|---|
| **Executing** — how you make things happen | Driver, Organiser, Finisher |
| **Influencing** — how you reach others | Persuader, Catalyst, Voice |
| **Relationship Building** — how you build bonds | Connector, Harmoniser, Empathiser |
| **Strategic Thinking** — how you take in the world | Analyst, Visionary, Learner |

## 3. Item format — forced-choice, timed

Each item presents **two self-descriptor statements** and asks the respondent to
indicate **which is more like them, and how strongly**, on a **5-point graded scale**
with a neutral midpoint. This is an **ipsative forced-choice** format: because the
respondent must trade one statement off against another, they cannot rate everything
highly, which controls **social-desirability** and **acquiescence** bias far better
than a Likert (agree/disagree) scale.

Each item has a **20-second time limit**. On timeout the response is recorded as
neutral. The limit is intentional: it captures a **spontaneous, top-of-mind
reaction** rather than a considered, self-curated one — the same rationale Gallup
gives for timing CliftonStrengths items.

## 4. Item bank and balancing

- **102 items**, drawn from a bank of ~12 statements per theme (9 positive + 3
  reverse-keyed).
- Items are generated by a **round-robin (circle-method) schedule** so that **every
  theme appears exactly 17 times** and **no theme is ever paired against itself**.
  Balanced exposure is a requirement for fair ipsative scoring — a theme that
  appeared more often would accumulate more opportunities to score.
- Item order and left/right position are randomised per session.

## 5. Scoring

For each answered item, the 5 scale positions allocate a fixed **2 points** between
the two statements:

| Position | → statement A | → statement B |
|---|---|---|
| Most like A | 2.0 | 0.0 |
| Slightly A | 1.5 | 0.5 |
| Neutral | 1.0 | 1.0 |
| Slightly B | 0.5 | 1.5 |
| Most like B | 0.0 | 2.0 |

A statement's allocation is **added** to its theme if it is positive, or
**subtracted** if it is reverse-keyed (§6). Theme totals are summed across the whole
session, then **min–max normalised to a 0–100 index** for display and ranked.

**Output:**
- A **full rank order** of all 12 themes (0–100 index).
- The **top 5** highlighted as **signature strengths** (the analogue of a "Top 5"
  report).
- A **domain balance** breakdown — each domain's share of total normalised score.

## 6. Validity features

- **Reverse-keyed statements** (3 per theme, ~43 of the 102 items involve one).
  Endorsing a reverse statement is evidence *against* its theme, so a theme can lose
  points. In a pure forced-choice format acquiescence is already suppressed; the
  reverse items add a second, independent check.
- **Response-consistency index** (High / Moderate / Low). For each theme the model
  compares average endorsement of its *positive* statements against its
  *reverse-keyed* statements. Strongly endorsing both is self-contradictory; the more
  themes show that clash, the lower the consistency rating.
  - *What it catches:* genuine self-contradiction / inattentive-but-patterned
    responding.
  - *What it does not catch:* uniform random clicking (which produces middling, not
    contradictory, averages). For that, add explicit duplicate or infrequency items
    as attention checks.

## 7. Psychometric caveats (read before using for assessment)

- **Ipsative data is intra-individual.** Scores describe strengths *relative to each
  other within one person*. Comparing a raw theme score across two people is
  statistically unsound — this is an inherent property of forced-choice/ipsative
  measures, not a defect of this build. **Do not rank candidates by theme score.**
  Use the profiles to inform individual discussion, not selection cut-offs.
- **Not normed (by design).** There is no population benchmark, so "you scored high
  on X" means high *for you*, not high versus others.
- **Reliability ≠ validity.** A larger item bank improves internal-consistency
  reliability; it does not establish that the themes predict any real-world outcome.
  Criterion and construct validity would require empirical studies against external
  measures.
- **Results are computed client-side** in the current build. For higher-stakes use,
  recompute and store scores server-side on submit so they cannot be tampered with.
